# Persona Test Profiles

Three persona builds for the nine actors at [actor-persona.pages.dev](https://actor-persona.pages.dev/), each facing the same backtest: predict the actor's own later actions from its own dated record.

- **index.html** — the viewer: the Key (structure and what was added/changed), and per-actor views of the three test profiles.
- **key.json** — the Key's content: how each test is built, the persona structure, additions and changes versus the source schema, and the exam protocol.
- **data/test1/** — Plain Record profiles: identity line, observed action menu (core/rare verbs), the full dated record, and the hidden after-cutoff answer key.
- **data/test2/** — Rule Cards: trigger → response → delay → size → direction, with episodes, stability checks, and cited background research.
- **data/test3/** — Expert Reads: four lens summaries per actor with row-cited claims, plus topic-to-lens routing and the generation method.
- **source-personas/, source-spec/** — snapshot of the source data pulled from actor-persona.pages.dev (personas, rows, specs), kept so the tests are reproducible.

Source data © the actor-persona project; test layers built for the persona-comparison experiment.
